# TERMINATOR — Sequencing / Transport / MIDI Architecture Dossier
Repo: `~/terminator` @ `mpc-stem-extractor`. All paths below are under `src/renderer/` unless absolute.

## 1. TRANSPORT MODEL

**Master clock = the single `AudioContext.currentTime`** created in `ChopperEngine` constructor (`chopper/ChopperEngine.ts:906-925`, `latencyHint:'interactive'`, optional `sampleRate` 44100/48000 + `bufferFrames` 128–1024 → `latencyHint = frames/rate` from desktop settings). Every engine (DrumEngine, BassEngine, MidiClockSender) receives this same ctx. There is no separate transport object — the chop sequencer in ChopperEngine IS the transport; drums, bass and MIDI clock out are "satellites".

**Tick source**: `lib/audioClock.ts:61-71` `startClock(tick, ms)` — one shared Blob **Worker** running `setInterval`, posting back to main (falls back to main-thread `setInterval` if Worker creation fails). All look-ahead schedulers tick at **25 ms**. `LookAhead(base=0.25 s, boosted=0.5 s, intervalMs=25)` (`audioClock.ts:79-90`): `beat()` marks a tick as late when gap > 3×interval (75 ms) → `horizon()` returns 0.5 s for the next 6 s, else 0.25 s. Used by chop seq (`ChopperEngine.ts:867`), metronome (`:870`), DrumEngine (`DrumEngine.ts:543`), BassEngine (`bass/BassEngine.ts:296`).

**Tempo**: `getMasterBpm()` (`ChopperEngine.ts:625-630`) = `metronomeBpm` (>0) else detected `bpm` else 120. `setMetronomeBpm` clamps **20..300** (`:4938-4947`); UI clamps 40..300. `seqTempo()`/`arpTempo()` same rule (`:5414, :4793`). Drum/Bass engines read BPM via callback `getBpm` each step — **no re-anchor on BPM change**; the new stepDur applies at the next scheduled step within ≤25 ms + horizon (comment `:4940-4945`). The one already-queued step keeps its old spacing; chop tails are hard-cut by `cutSeqTails` if the next note now lands earlier (`:6043-6060`).

**PLAY (`playSeq`, `:5891-5936`)**: `stopSeq()` first (with `seqRestarting=true` so satellites keep REC armed) → `seqPlayStart = ctx.currentTime + TRANSPORT_LEAD_S` (**0.02 s**, `:869`) → `seqCurrentLoopStart = seqScheduledUpTo = seqPlayStart`, `seqScheduleStep=0`, `seqStepDuration = (60/bpm)·(4/resolution)` → prime `seqSchedulerTick()` synchronously → `startClock(25)` → **`seqStartHook(seqPlayStart)`** → satellites. Hook wiring: `ChopperView.tsx:796-801`: `drumEngine.start(at); bassEngine.start(at); midiClockRef.start(at)`; stop hook `drumEngine.stop({keepRec: restart}); bassEngine.stop(); midiClock.stop()`. `HardwareView.tsx:719-724` identical minus MIDI clock. `startTransport` also calls `drumEngine.start()`/`bassEngine.start()` unconditionally (idempotent) for the no-sample case (`ChopperView.tsx:805-814`). `playSeq` refuses when `!hasSequenceableAudio()` (main buffer OR any pad buffer, `:805`).

**Chop step scheduler (`seqSchedulerTick`, `:6230-6286`)**: (1) pop `seqBoundaries` whose `time <= now` → update audible anchor `seqCurrentLoopStart`, `seqStepDuration`, `playingSeqIdx`; (2) non-loop end: `seqStopAt>0 && now>=seqStopAt` → stop; (3) `while (seqScheduledUpTo < now + horizon)`: at step 0 adopt `queuedSeqIdx` (pattern switch only at loop boundary) and push a boundary record; `stepCount = min(1536, bars·resolution)`, `stepDur = 60/bpm·4/resolution` re-read per step; `scheduleSeqStepAudio(...)`; `seqScheduledUpTo += stepDur`. Non-loop: `seqStopAt = seqScheduledUpTo` after the last step. `guard<512`.

**Step audio (`scheduleSeqStepAudio`, `:6072-6213`)**: late rule — `late = now - startAt`; if `late >= stepDur - 0.005` drop; else start now with `skipBuf = late·rate` into the chop. Filters pads hand-played within **0.12 s** (`lastLivePadHit`) — "one owner per hit". A `setTimeout(chokeDelay)` chokes ringing live voices in the firing mute groups (timer jitter only affects the choke, not audio start). Note length: until the next step where the same **mute group** fires (wrapping if loop) else pattern end, `maxDur = steps·stepDur`. Voice: `AudioBufferSourceNode`, `detune = (pad.pitch + sourcePitch)·100`, `rate = 2^(semis/12)`, `bufDur = min(chopDur − skipBuf, (maxDur−late)·rate)`, `src.start(startAt, startSec, bufDur)`; gain env: 0 → `vel` over `atk = clamp(attackFor(pad), 0.0005, realDur−0.005)`, hold, **5 ms** linear to 0.0001 ending at `startAt+realDur` (`:6182-6192`). Reverse = global/per-pad `reversedFor()` at playback (revGrid kept as data only, `:6136-6140`). Tails tracked in `seqTailVoices`; `cutSeqTails` cuts earlier same-group tails with a 5 ms ramp when overlapped.

**⚠ Swing on the chop seq — live vs export mismatch**: `seqSwingOffsetSec(step, resolution)` (`:5582-5586`, `idx16 = floor(step·16/resolution)` → `swingOffsetSec`) is applied ONLY in the export path `patternToEvents` (`:6858`). `scheduleSeqStepAudio` uses the straight `seqScheduledUpTo`. `setSeqSwing` is mirrored from the drum SWING knob (`ChopperView.tsx:1700`) and the UI tooltip promises "one knob swings both sequencers" (`drums/DrumSection.tsx:742`). Live chop playback is straight; exports swing. Verify before porting — pick one.

**Swing formula (`lib/swing.ts:7-17`)**, shared drums/chop/export: for odd 16th index only (`step16 % 2 === 1`), `stepDurMs = 60000/bpm/4`, `pulseDurMs = 60000/bpm/96`, `swung = s·stepDurMs/2`, `quantized = round(swung/pulseDurMs)·pulseDurMs`, `finalMs = swung + s·(quantized − swung)`; returns seconds. s ∈ [0,1]; s=1 ≈ full triplet (~66.7% MPC). Downbeats never move; the look-ahead grid stays straight (only hit time is offset).

**Pause/Resume (`:5950-6033`)**: pause freezes `seqPausedElapsed = now − seqCurrentLoopStart`, stops scheduler + metronome + all scheduled sources; `seqPlaying` stays true. Resume: `seqCurrentLoopStart = now+0.02 − pausedElapsed`, `seqPlayStart` shifted by the same delta, next step = `ceil(pausedElapsed/stepDur)`. Pause does NOT call the stop hook (drums keep running — satellites aren't paused).

**STOP (`stopSeq`, `:6288-6316`)**: cancel count-in, stop scheduler, clear `loopTimers`, `src.stop()` every `scheduledSources`, clear tails/boundaries, `liveRecording=false`, `queuedSeqIdx=null`, `seqStopHook(seqRestarting)`, stop metronome timer (flag kept). Panic `killAllAudio` (`ChopperView.tsx:840-845`) = `stopSeq + bass.panic + drums.stop + stopAllPads` (3 ms fade, `:4737-4749`).

**Cursor**: `getSeqCursorStep/Phase` (`:6318-6366`) derive from `seqCurrentLoopStart` (audible anchor, not look-ahead); Timeline.tsx rAF divides phase by `stride` (`Timeline.tsx:91`).

**Step resolution model (grid-is-a-lens)** — memory note `project_drum_seq_resolution.md` + code:
- Chop seq: `SeqPattern {bars, resolution (STORED spb), viewResolution, grid[step]=pad[], revGrid, velGrid, loop}` (`:269-287`). `SEQ_RESOLUTIONS = {2,3,4,6,8,12,16,24,32,48,64,96,128,192}` (triplets = straight×1.5); `SEQ_MAX_STEPS=1536` stored, `SEQ_MAX_VIEW_STEPS=512` columns (`:533-538`). `refitSeqStorage(view, floor)` (`:5465-5526`): `C=lcm(old,view)`, `g = gcd(C/view, s·up for every occupied step)`, `next = C/g` (coarsest multiple of view keeping every note integral); with a `floor` (192 during live-record at INPUT Q<100, `ensureRecordStorage :5770`) picks the finest allowed multiple ≤ floor within cap. Mid-play rescale: `seqScheduledUpTo += (ns/ratio − seqScheduleStep)·oldDur`, `seqScheduleStep = ceil(step·ratio)`, boundaries' `stepDur` rewritten. Defaults: bars 2, resolution 4 (engine) / `sequences[0]` res 16 (`:785-818`). Bars 1..4. Invariant `seqResolution % seqViewResolution === 0`; `seqColumnStride = round(res/view)`.
- Drums: fixed `INTERNAL_SPB = 96` (`DrumEngine.ts:201`), `GEN_SPB=16` generators, views `STEP_DIVISIONS=[8,16,32]` × triplet(×1.5) → stride 12/6/3 or 8/4/2. `stepDurSec = 60/bpm·4/96` (`:964-968`). Old presets `gridRes` absent → upscale by `stepDivision`; `gridRes=32` → ×3 (`:1105-1117`). `MAX_STEPS = 4·96 = 384` graph length. Bars 1..4 (UI offers 1/2/4).

**Pattern/sequence model**: chop `sequences[]` with `currentSeqIdx` (edited) vs `playingSeqIdx` (audible) vs `seqScheduleIdx` (being filled) vs `queuedSeqIdx` (switch at next loop boundary, `selectSequence :5344-5369`; non-loop → immediate stop). Drums: `sequences[]` + `seqIndex`, `pattern` mirrors the active one; switching is immediate (no boundary queue) (`:1493-1514`). No song/chain mode in the live transport — the **Arranger** (§3) is the song mode. Bass: own patterns, 96 PPQ tick map.

**Record/overdub/step-input**:
- Chop STEP record (`startRecordingSeq :5677`, `_doTrigger :4304-4324`): cursor walks columns (`stride`), writes `[padIdx]` replacing the cell, `revGrid=[reverseSample]`, `velGrid=[clampVel(v)]`, skips filled columns (`advanceRecordToEmpty`).
- Chop LIVE record (`startLiveRecord :5778`): forces `seqLoop=true`, `ensureRecordStorage`, count-in if enabled (4 beats, clicks at `now+0.12 + i·beatDur`, downbeat callback 20 ms early; `scheduleCountIn :5827-5849`, uses `setTimeout`). Hit time `hitTime = now − eventLag(≤50 ms) − hwLatencySec()` (`:4246-4249`). Landing: `liveLanding(elapsed, stepDur, stride, strength)` (`:550-558`): `line = round(elapsed/gridDur)·gridDur`, `corrected = elapsed + s·(line−elapsed)`, `step = round(corrected/stepDur)`, `at = step·stepDur`. Audible hit scheduled at `lineT` via `triggerPadAt` if > now+2 ms else now; if the pad was already on that step and `lineT <= seqScheduledUpTo` (booked) it's not double-fired (`:4258-4291`). Early hits during count-in kept if within half a grid step before the downbeat (`flushEarlyHits :5758`).
- INPUT Q: global 0..100 on ChopperEngine (`inputQuantize`, default 100, `:772`), drums read via `getInputQuantize` callback; migrated from `drums._inputQuantize` (`:3411-3415`).
- `hwLatencySec()` (`:2705-2708`) = `ctx.outputLatency` if >0 else `0.02 + baseLatency`.

## 2. DRUM MACHINE (`drums/DrumEngine.ts`)

**Data model** (`DrumState :102-130`): `tracks: DrumTrack[]` — `{key, name, color, kitKey?, added?, sampleIndex, sampleGenre, userPath?, userName?, userMissing?, muted, solo, volume 0..1, muteGroup?}`; defaults `TRACK_DEFS` kick/snare/hihat(0.25)/openhat(0.25)/perc(0.5) (`:174-180`), user lanes `user<n>` colours cycled (`:2395`). `pattern: Record<key, boolean[]>` length `bars·96`; `sequences[]`, `seqIndex`, `bars` (default 2), `masterVolume`, `genre` ('boombap'|'trap'|'westcoast', default trap), `drumSwing` 0..1, `stepDivision` (16), `triplet`, `gridOff`, `ppq` ∈ {24,48,96,192,480,960} default 960, `stepRecording`, `liveRecording`, `drumRecordStep`, and four engine-level (shared across sequences) graphs length 384: `stepVelocity` (0..1, def 1), `stepShift` (ms −50..50), `stepPan` (−1..1), `stepRepeat` (index into `REPEAT_RATES` 0..12: off,1/2,1/2T,1/4,1/4T,1/8,1/8T,1/16,1/16T,1/32,1/32T,1/64,1/64T; `beats·60/bpm` interval, `:230-244`). No probability, no flams. Preset shape `DrumPreset :134-168`.

**Transport**: `start(atTime?, stepOffset=0)` (`:1667-1710`): claims `playing` synchronously before `await resume()`, `preload()`, `nextStepTime = atTime ?? now+0.02`, `playStartTime = nextStepTime − stepOffset·stepDur`, flush early hits (window = half a view column), `scheduleAhead()` then 25 ms clock. `getStep()` = `floor((now−playStartTime)/stepDur) % total` (`:1202-1210`). `stop({keepRec})` (`:1716-1743`): chokes every voice 4 ms and `src.stop(t+0.006)`, clears `pendingPatterns`, disarms REC/STEP unless restart.

**scheduleAhead (`:1763-1798`)**: `horizon = now + look.horizon()`; stall catch-up: if `now − nextStepTime > stepDur` jump whole steps (`missed = floor(...)`, both `nextStepTime` and `nextStepIdx`) — phase preserved from `playStartTime`; then book steps. `scheduleStep(stepIdx, when)` (`:1824-1897`): drop if `now − when >= stepDur − 0.005`; `pattern = patternFor(when + stepDur/2)` (arranged-playback swap list, half-step tolerance for float drift); `baseTime = when + swingOffset(stepIdx)` where `swingOffset` converts to 16th slot `floor(stepIdx/6)` (`:1808-1822`); solo-over-mute; skip if hand hit within `LIVE_OWNER_WINDOW=0.12 s`; SHIFT snapped to `pulseSec = 60/bpm/ppq`; `shiftedTime = max(now+0.001, baseTime+shiftSec)`; `vol = track.volume·stepVel`; REPEAT: sub-hit times from `shiftedTime` every `interval` until `nextStepTime−0.001`, each self-choking into the next (`chokeAt`).

**Voice engine (`emitVoice :2066-2149`)**: gain env `applyDrumAttack` (`:404-412`): head level (first 1 ms, all channels) < **0.02** → `setValueAtTime(target, when)` instant; else 0 → target linear over **3 ms** (`DRUM_ATTACK_S`). Optional `StereoPannerNode`. Retrigger rule (time-ordered `laneVoices[track]`): every voice with `startAt <= when` is choked at `when`; a voice booked later becomes this voice's `endAt`. Mute groups (`muteGroups.ts`): same rule across lanes sharing `muteGroup`; "same instant = layer, not cut" (`groupCutTime :39-47`). `chokeVoice` (`:2056-2063`): `holdGainAt` = `cancelScheduledValues(t) + setValueAtTime(level, t)` (NOT `cancelAndHoldAtTime` — measured not to hold, `:34-51`), then linear to 0 over **`DRUM_CHOKE_S = 0.004`**; gain-only, source never stopped by a choke (only by transport STOP). Sub-hits: `setValueAtTime(target, max(when+attack, ch−0.004))`, ramp to 0 at `ch`, `src.stop(ch+0.01)`, start before stop. One-shot only (no gate); `playLive` (`:2193-2209`) plays at `ctx.currentTime` (or a MIDI-compensated `when`), stamps `lastLiveHit`. Output: per-lane tap GainNode → route gain (5 ms crossfade on re-route `ROUTE_XFADE_S`) → drum `masterGain` or a mixer strip.

**Sample loading (`loadUrl :1926-1966`)**: candidates from `drumSampleUrls(id)` (local copy → lossless R2 FLAC → mp3 fallback; R2 under opaque ids), `decodeAudioData`, then `ceilPeak` (scale down to **0.977 = −0.2 dBFS**, never boost), `declickHead` (linear fade over ≤3 ms ending at first −6 dBFS sample; skipped if head < 0.002), `declickTail` (raised-cosine 5 ms). `LruBufferCache` 64 MB. Lazy on first hit; cold hit plays at `max(when, now+0.001)`, never dropped.

**Generate (`generate :1596-1660`)**: trap → `generateTrap` from `TRAP_PATTERNS` bank of 50 built with coprime strides (kick i, snare 3i, hat 7i, openhat 11i, perc 17i, `generate.ts:180-199`), tiled to `bars·16`; boombap/westcoast → fetch `/api/midi-files?genre=boombap` (KCC origin in Electron), weighted pick (75% top third, `:113-119`), parse SMF note-ons to 16ths (`parseMidiToSteps`, map 35/36 kick, 37/40 snare, 38/42/44 hihat, 39/46 openhat, `step = round((tick−minTick)/(ppq/4)) % total`), fallback built-in bank (`:1615-1660`). All upscaled ×6 onto 96 (`upscaleFromGen`).

**Live record (`liveHit :2282-2314`, `recordLiveHitAt :2326-2367`)**: `intent = now − lag − outLatSec()`; grid ON + playing + REC: `nearest` view line, `lineT`, write first; audible at `max(now, intent + s·(lineT−intent))` unless booked; grid OFF: play now, record free. Write: `stepsElapsed = (t−playStartTime)/stepDur`, `nearestView = round(stepsElapsed/stride)·stride`, `corrected = stepsElapsed + s·(nearestView−stepsElapsed)`, `snapped = gridOff ? nearestView : round(corrected)`, residual `(corrected−snapped)·stepDur·1000` ms → SHIFT (0 if |res|<0.5). Emits throttled at 10 fps (`SEQ_FLUSH_SEC=0.1`). STEP record (`recordStepHit :2499-2516`) cursor advances one column.

**Per-lane mixer**: mute/solo/volume on the track; desktop `routeTrackOutput` peels a lane to a MixerEngine strip (kick/snare/hat/openhat/perc fixed, user lanes named by key, `arranger/renderArrangementDAW.ts:40-64`).

## 3. ARRANGER (`arranger/`)

`types.ts`: `Arrangement {name, sections[], bassPatch?}`; `ArrangementSection {name, bars, chops[], drums: DrumVariation, dynamics?, enabledDrumTracks?, chopEvents?: {beat, pads[], rev?}[], drumPattern?: Record<key, boolean[]>, drumStepsPerBar? (DECLARED; absent=16), bassNotes?: {beat,note,dur,vel,slide?}[], bassBends?}`. `payload.ts` builds the AI request (compact chop indices → pad map, `bpm = round(getMasterBpm()) || 90`).

**Live preview (`ArrangerPreview.ts`)**: `anchor = now + 0.08`, `startTime = anchor − startBeats·beatDur`; drums: `schedulePattern(patternForSection, anchor+cursor)` per section then `drums.start(anchor, round(offsetSec/stepDur))` with `stepDur = barDur/drums.stepsPerBar`; bass: `playTimeline` absolute notes (tag 'arr'); chops: event list `{at, fn}` pumped by a **main-thread `setInterval(25)`** with `LOOKAHEAD = 0.2 s`, firing `engine.triggerPadAt(pad, startTime+at, 1, {reverse})` (`:133-189`). `triggerPadAt` (`ChopperEngine.ts:4166-4196`) starts the voice at absolute `when`; the group choke runs on a `setTimeout(delay)`. Ends at `total+0.25`. Drum variation mapping `:253-266` (breakdown=kick+snare, hi_hats_only=hihat+openhat, none=[]).

**Export (`exportArrangement.ts`)**: `buildChopEvents` (cut at next distinct hit time, rounding 1e-4 s, default ring 2 beats, min 0.05 s); `buildDrumTrackHits` (`:156-194`): `spb = max declared`, `stepDur = 4·beatDur/spb`, continuous global step `g`, `drumRowAt` tiles rows (`row[i % row.length]`), swing `drumSwingOffsetSec(floor(g/per16th))`, graphs indexed by live loop index `li = round(g·96/spb) % (bars·96)`, SHIFT snapped to ppq pulse, REPEAT expanded with `chokeAt`; mute groups via `annotateGroupCuts`. `TAIL = 2.5 s`. DAW path `renderArrangementDAW.ts` renders drum lanes per track offline with `applyDrumAttack` + 4 ms choke at `min(next own, groupCutAt)` (`:111-126`), strip FX, sends, PDC shift, master. MPC export: `MPC_PPQ=960`, `stepTicks=240`, note `36+pad`, swing converted to ticks (`:286`), chops straight.

## 4. MIDI

**Hub (`chopper/midiHub.ts`)**: one `requestMIDIAccess({sysex:false})`, `addEventListener('midimessage')` per input, explicit `port.open()`, `onstatechange` + visibilitychange rebind, status `'unsupported'|'requesting'|'denied'|'ready'|'nodevice'`, last-message monitor (clock/active-sensing excluded), `outputs()` opens connected outputs. Legacy `audio/MidiInput.ts`, `audio/Metronome.ts`, `audio/Quantizer.ts`, `components/Transport.tsx` belong to the old `audio/AudioEngine.ts` tree (only `WaveformDisplay.tsx` imports it; not the live engine) — ignore for the port.

**Note→pad**: `midiPads.ts` `MPC_PAD_BASE_NOTE = 36` (A01=C1), `padIndexForNote(note) = note−36` or null. Desktop ChopperView default map `note→note−36` for 36..127 (`ChopperView.tsx:1272-1282`), remappable per-note via pad learn (`:1924-1929`; `setMidiMap`); mobile HardwareView uses `padIndexForNote` directly (`HardwareView.tsx:1664`). Velocity = `velocity/127` → `triggerPad(pad, vel, e.timeStamp)` (`:2019`), gain = vel (× source NORM) — linear, no curve (`ChopperEngine.ts:4444-4450`); sequencer cell velocity floor `clampVel` 0.05..1 (`:25`). Note-off → `releasePad` (gate pads fade over master `release`, min 5 ms, `:4686-4704`). DRUM PADS mode: pad i → drum lane i via `drumEngine.liveHit(idx, e.timeStamp)` or step-rec `playLive(key, 0, when)` + `recordStepHit` (`ChopperView.tsx:1981-1999`). Bass MIDI IN: `noteOn(note, vel/127, when)`; MPC/MPD port-name regex → `mpcNoteOn` (pad = scale degree) (`:1963-1975`); pitch bend 14-bit → `setBend(±bendRange)`. Tap-tempo note, kill note, learnable.

**Handler-lag compensation**: `lag = clamp((performance.now() − e.timeStamp)/1000, 0, 0.05)`; bass/drum step path `when = max(now, now − lag + baseLatency)`.

**CC / MIDI learn**: `MidiMap.ts` (Electron-only, parameterId → `{min,max}`, scale `min + v/127·(max−min)`, persisted `midi-map.json` via IPC; learn mode click-to-arm, chainable) → fallback `midiLearn.ts` (paramId→CC, `localStorage 'terminator.midiCcMap.v1'`, mirrored into midi-map.json under `__ccMap`, right-click arm, Escape/outside-click cancel). Both use `LearnPicker` (`midiLearnPick.mts`): bind on first value 1..126; never bind a 14-bit LSB (cc 32–63 within 80 ms after cc−32); end-stop-only CCs bind on the 3rd message.

**MIDI clock IN (`midiClockIn.ts` + `ChopperView.tsx:1880-1896`)**: Real-time bytes matched on the full status before masking. START/CONTINUE (0xFA/0xFB) → `MidiClockSourceLock.onStart(port, ts)` (same press on another port within `DUPLICATE_MS=500` ignored) → `clockFollow.reset()`, transport start; STOP (0xFC) any port → stop + unlock. 0xF8 ticks: only owner port, only while hardware-started AND Preferences "follow tempo" on (default OFF) → `MidiClockFollower.onTick(e.timeStamp)`: dropout reset >1000 ms; tempo-jump detection (interval deviates >15% from window mean for 3 ticks → keep last 3); window 48 ticks, min 25 before first estimate; least-squares slope ms/tick → `bpm = round(60000/(perTick·24)·10)/10`, range 20..400, hysteresis 0.3 BPM, ≤1 report per 24 ticks → `engine.setMetronomeBpm(bpm)`. The "reads 2×" bug (89→177) was multi-port duplicate ticks — fixed by the lock on desktop; **HardwareView has no lock** (`HardwareView.tsx:1643-1645`) and ignores clock entirely.

**MIDI clock OUT (`midiClockOut.ts`)**: `PPQN=24`, `secondsPerTick = 60/clamp(bpm,20,400)/24`, `CLOCK_LOOKAHEAD_S=0.15`, `CLOCK_PUMP_MS=25` (Worker clock), `CLOCK_STALL_SKIP_S=1.0`. `start(anchor)`: SPP `[F2,0,0]` + START `[FA]` stamped at the anchor, then `bookTicks` from the anchor to `now+0.15`, BPM re-read per tick; ctx→MIDI ms via `getOutputTimestamp()` pair, else `performance.now() + Δ·1000`; `stop()` sends `[FC]` now (booked ticks past now still go out — no `MIDIOutput.clear()`). Stall >1 s skips whole ticks; shorter stalls deliver late bunched ticks (count = song position). Outputs filtered by Preferences `midi.outputs[id] !== false`; enabled by `settings.midi.clock`. No SPP on restart other than 0 (always from the top).

**Latency meter (`MidiLatencyMeter.tsx` + `ChopperEngine.ts:2717-2765`)**: OUT = `hwLatencySec()·1000` (flag `outputMeasured` if `ctx.outputLatency>0`); IN = median of last 48 `performance.now()−e.timeStamp` samples (discard <0 or >0.5 s), worst reported; polled every 500 ms; double-click resets. No MIDI note OUT exists.

## 5. TIMING PRECISION — what decides sample accuracy today

| Path | Mechanism | Precision |
|---|---|---|
| Chop seq / drums / bass / metronome audio | `src.start(absoluteCtxTime)` / worklet `at` booked from a Worker 25 ms tick, 0.25–0.5 s horizon | sample-accurate vs ctx clock as long as the main thread returns within the horizon |
| Transport anchor | `now + 0.02` shared via `seqStartHook` | drums/bass/clock phase-locked by construction |
| Stall handling | chop: drop if whole slot passed else start late with offset; drums: jump whole steps, drop past steps; metronome: skip beats ≥50 ms past; clock out: >1 s skip | no burst replay |
| Live pad hits | `startVoice` at `ctx.currentTime` (immediate), MIDI lag only used for record quantize / bass & drum `when` | subject to handler latency (measured by meter) |
| Chop-seq group chokes, `triggerPadAt` chokes, count-in visuals/downbeat, arp | **`setTimeout`** | ms-level jitter (affects chokes/arp, not scheduled starts) |
| Arp (`:4803-4835`) | `_doTrigger` immediate from `setTimeout` aimed at `arpStart + step·interval`, `interval = 60/bpm/arpRate` | drift-free target, jittery fire |
| ArrangerPreview chop events | main-thread `setInterval(25)` pumping `triggerPadAt` 0.2 s ahead | accurate starts; interval throttled when hidden |
| ChopperView live-record audible quantize | `triggerPadAt(lineT)` | accurate |
| Cold drum buffer | plays at `max(when, now+0.001)` | late once |
| "300 ms before loop end" | historical comment only (`:6357-6359`); current design queues one step at a time to the 0.25 s horizon | — |

Latency compensation on record: `hwLatencySec()` (outputLatency else 0.02+baseLatency) subtracted from hit times in both engines; input lag capped 50 ms.

## 7. WEB-AUDIO / ELECTRON LIMITATIONS & KNOWN ISSUES

- `cancelAndHoldAtTime` does not hold without a spanning event (Chrome, measured `DrumEngine.ts:34-51`) → explicit cancel+set.
- Past automation on a voice started at `ctx.currentTime` is skipped → click guard baked into buffers (`declickHead`), not a gain ramp (`:299-308`).
- `MIDIOutput.clear()` unimplemented → ticks past STOP leak a few ms.
- iOS: context 'interrupted', timers held during scroll (Worker clock), no scheduling onto a non-running ctx (`scheduleAhead` guard), scheduler parked on hidden only when ctx not running.
- Output device swap: ctx pinned to endpoint → `reopenOutput` on `devicechange` (250 ms debounce).
- Safari `outputLatency` undefined → 20 ms estimate flagged `~`.
- Count-in, arp, chop-seq chokes, `triggerPadAt` chokes, ArrangerPreview pump run on `setTimeout/setInterval` (main thread).
- Chop seq live playback ignores `seqSwing` (§1) while export/MPC apply it; MPC export keeps chops straight by design (`exportArrangement.ts:249`).
- Mobile MIDI path: no `MidiClockSourceLock`, no clock-follow.
- Drum pattern switch (`selectSequence`) is immediate, chop's is boundary-queued.
- `Metronome.ts`/`Quantizer.ts`/`MidiInput.ts`/`Transport.tsx`/`AudioEngine.ts` = dead legacy.
- ChopperEngine `metronomeSchedulerTick` clicks route to `ctx.destination` directly (not through mixer).

## 8. SUBTLE BEHAVIOURS EASY TO BREAK

1. Audible anchor vs schedule cursor are separate (`seqCurrentLoopStart` advances only when a boundary's time passes); playhead, live-record quantize, and pattern-switch all read the audible one.
2. Pattern switch/clear/tempo apply at the next *unscheduled* step; queued swap only at step 0; `queuedSeqIdx` cleared at every step-0 pass.
3. Drum `patternFor(when + stepDur/2)` half-step tolerance; arranged swaps must sit on step boundaries.
4. Time-order choke rule: earlier-started voices are cut by a new hit; later-booked voices cut it (both lanes and mute groups); same-instant = layer.
5. "One owner per hit" windows: chop 0.12 s (`lastLivePadHit`), drums `LIVE_OWNER_WINDOW=0.12`; booked-vs-unbooked decided by `lineT <= seqScheduledUpTo` / `nextStepTime`.
6. Live-record: write uses the same instant as the audible scheduled hit (`liveLanding.at === step·stepDur`); drums store the residual in SHIFT (±50 ms, 0 if <0.5 ms) and snap SHIFT to the `ppq` pulse at playback.
7. Output-latency comp applied exactly once (`recordLiveHit` → `recordLiveHitAt`); early count-in hits already carry it.
8. Drum swing indexes 16ths (`floor(step/6)`), chop swing `floor(step·16/res)`; the look-ahead grid itself is never swung; REPEAT rolls fill the *straight* slot.
9. Drum `stepsPerBar` is 96 for `start(at, stepOffset)`; ArrangerPreview seeks in engine steps (`barDur/stepsPerBar`).
10. `refitSeqStorage` keeps notes integral via lcm/gcd and rescales a running scheduler in place; `ensureRecordStorage` raises storage to 192 when IQ<100.
11. Graph rows are engine-level (shared across drum sequences), length 384, indexed by internal step; export reindexes via `li = round(g·96/spb) % (bars·96)`.
12. `drumStepsPerBar` is declared per section — never infer from `row.length/bars`; rows tile (`% row.length`).
13. Transport lead 20 ms; ArrangerPreview 80 ms; count-in first click +120 ms, downbeat callback 20 ms early; standalone drum start +20 ms; bass honours an anchor up to 50 ms old.
14. `DrumEngine.start` claims `playing` before the async resume so the hook + `startTransport` double call yields one scheduler; `stop` during the await is honoured.
15. `stop({keepRec:true})` only from the chop `seqRestarting` path; real STOP disarms REC/STEP and clears early hits.
16. Chop gate (NOTE ON) pads and ARP bypass audible quantize (write still quantized); LOOP pad re-hit toggles it off.
17. Velocity floor 0.05 in cells, 1 default; `toggleSeqStep` captures `reverseSample` into `revGrid` but playback reads live `reversedFor(pad)`.
18. Chop `metronomeBpm` persisted separately from detected `bpm`; preset load sets metronomeBpm only when it was 0/120 (`:1224, :2996`).
19. MIDI System Real-Time must be matched before `& 0xf0`; 0xF8/0xFE must return before the pad path.
20. Drum voice `source` is `stop()`ped only by transport STOP (and sub-hits); everything else is gain-only so a later earlier-cut can still be applied.
